Introduction to JavaScript

Beginner 5 min

JavaScript is a versatile, high-level programming language that powers interactive behavior on websites. It's the third layer of standard web technologies alongside HTML and CSS.

Key Insight

JavaScript was created in just 10 days by Brendan Eich in 1995 while working at Netscape.

Tamil Explanation
இணையதளத்தின் உயிர்.
HTML என்பது எலும்புக்கூடு (Skeleton). CSS என்பது தோல் (Skin). JavaScript என்பது மூளை (Brain) மற்றும் உயிர் (Soul). ஒரு பட்டனை அழுத்தினால் என்ன நடக்க வேண்டும் என்பதை JS தான் தீர்மானிக்கிறது.
JavaScript in Action
Without JavaScript
<button>Click Me</button>
// Nothing happens when clicked
With JavaScript
<button onclick="alert('Hello!')">
    Click Me
</button>
// Shows alert when clicked

Variables & Scope

Beginner 8 min

Variables are containers for storing data values. JavaScript uses three keywords to declare variables: var, let, and const.

var

Legacy

Function-scoped, can be redeclared and updated.

var name = "John";
var name = "Jane"; // ✅ Allowed
Avoid in modern code

let

Recommended

Block-scoped, can be updated but not redeclared.

let age = 25;
age = 26; // ✅ Allowed
let age = 27; // ❌ Error
Use for variables that change

const

Recommended

Block-scoped, cannot be updated or redeclared.

const PI = 3.14;
PI = 3.15; // ❌ Error
Use for values that won't change

Operators

Beginner 12 min

Operators are symbols that perform operations on variables and values. JavaScript includes arithmetic, assignment, comparison, logical, and other operators.

Arithmetic Operators

+ Addition 5 + 2 = 7
- Subtraction 5 - 2 = 3
* Multiplication 5 * 2 = 10
/ Division 5 / 2 = 2.5
% Modulus 5 % 2 = 1
** Exponentiation 5 ** 2 = 25

Assignment Operators

= Assignment x = 5
+= Add and assign x += 3 // x = x + 3
-= Subtract and assign x -= 3 // x = x - 3
*= Multiply and assign x *= 3 // x = x * 3
/= Divide and assign x /= 3 // x = x / 3
%= Modulus and assign x %= 3 // x = x % 3

Comparison Operators

== Equal to (value) 5 == "5" // true
=== Strict equal 5 === "5" // false
!= Not equal 5 != "5" // false
!== Strict not equal 5 !== "5" // true
> Greater than 5 > 3 // true
< Less than 5 < 3 // false

Logical Operators

&& AND true && false // false
|| OR true || false // true
! NOT !true // false
?? Nullish Coalescing null ?? "default" // "default"
Tamil Comparison
== vs === வேறுபாடு:
== என்பது வெறும் மதிப்பை மட்டும் சரிபார்க்கும். "5" மற்றும் 5 ஒன்றாகும்.
=== என்பது மதிப்பு மற்றும் வகை இரண்டையும் சரிபார்க்கும். "5" (சரம்) மற்றும் 5 (எண்) வெவ்வேறு.

Type Conversions

Beginner 8 min

JavaScript can convert values from one type to another automatically (implicit conversion) or manually (explicit conversion).

Implicit Conversion

Automatic type conversion by JavaScript

"5" + 2      // "52" (string concatenation)
"5" - 2      // 3 (string to number)
"5" * "2"    // 10 (both strings to numbers)
true + false // 1 (booleans to numbers)
5 + null     // 5 (null becomes 0)
"5" + null   // "5null" (null becomes "null")

Explicit Conversion

Manual type conversion by developer

String(123)        // "123"
Number("123")      // 123
Boolean(1)         // true
parseInt("10px")   // 10
parseFloat("3.14") // 3.14
+ "123"             // 123 (unary plus)
!!1                 // true (double NOT)
Tamil Explanation
தானாகவே மாற்றுதல் vs நாம் மாற்றுதல்:
JavaScript சில நேரங்களில் தானாகவே மதிப்புகளை மாற்றும் (Implicit). எடுத்துக்காட்டாக: "5" + 2 = "52"
நாம் குறிப்பாக மாற்ற வேண்டும் என்றால் (Explicit): Number("5") + 2 = 7

Hoisting

Intermediate 10 min

Hoisting is JavaScript's behavior of moving declarations to the top of their scope before code execution.

var Hoisting

Variables are hoisted and initialized with undefined

console.log(x); // undefined
var x = 5;

Declaration is hoisted, assignment stays

let/const Hoisting

Variables are hoisted but not initialized (Temporal Dead Zone)

console.log(y); // ❌ Error
let y = 5;

Cannot access before declaration

Function Hoisting

Function declarations are fully hoisted

sayHello(); // ✅ "Hello!"
function sayHello() {
    console.log("Hello!");
}

Can call before declaration

Conditions

Beginner 15 min

Conditional statements control the flow of execution based on different conditions.

If / Else

Execute code if a condition is true

if (hour < 12) {
    console.log("Good morning");
} else if (hour < 18) {
    console.log("Good afternoon");
} else {
    console.log("Good evening");
}

Switch

Select one of many blocks to be executed

switch (day) {
    case 0:
        text = "Sunday";
        break;
    case 6:
        text = "Saturday";
        break;
    default:
        text = "Weekday";
}

Ternary Operator

Short hand for if/else

let status = (age >= 18) ? "Adult" : "Minor";
Tamil Explanation
If/Else: "மழை பெய்தால் குடை எடு, இல்லையென்றால் சும்மா போ" போன்றது.
Switch: டிவி ரிமோட் போல - 1 அழுத்தினால் Sun TV, 2 அழுத்தினால் KTV.
Ternary: ஒரே வரி if/else. "பாஸ் அல்லது ஃபெயில்?" என்பதை ஒரே வரியில் சொல்லலாம்.

Loops

Beginner 12 min

Loops can execute a block of code a number of times.

For Loop

Loop a specific number of times

for (let i = 0; i < 5; i++) {
    console.log(i);
}

While Loop

Loop while a condition is true

while (i < 10) {
    console.log(i);
    i++;
}

For...of

Loop through values of an iterable

let cars = ["BMW", "Volvo"];
for (let car of cars) {
    console.log(car);
}
Tamil Explanation
For Loop: "5 முறை தோப்புக்கரணம் போடு" என்று சொல்வது போல.
While Loop: "மழை நிற்கும் வரை காத்திரு" - எப்போது நிற்கும் என்று தெரியாது,
For...of: ஒரு கூடையில் உள்ள ஒவ்வொரு பழத்தையும் எடுத்து வைப்பது போல.

Async / Await

Advanced 20 min read

Asynchronous programming allows long-running operations (like I/O) to run without blocking the execution thread.

Promise

An object representing the eventual completion or failure of an async operation.

let myPromise = new Promise(function(resolve, reject) {
    setTimeout(function() {
        resolve("Success!");
    }, 1000);
});

myPromise.then(function(value) {
    console.log(value);
});

Async/Await

Syntactic sugar for Promises. Makes async code look synchronous.

async function myFunc() {
    let response = await myPromise;
    console.log(response);
}
Tamil Explanation
Sync vs Async:
Sync: ஓட்டலில் வரிசையில் நின்று பில் கட்டுவது. ஒருவர் முடித்த பின் தான் அடுத்தவர்.
Async: ஓட்டலில் ஆர்டர் கொடுத்துவிட்டு காத்திருப்பது. ஆர்டர் வரும் வரை நீங்கள் போன் பார்க்கலாம் (வேறு வேலை செய்யலாம்). உணவு தயாரானதும் (Promise Resolved), சாப்பிடலாம்.

Proxies

Advanced 15 min read

Proxy Object

Wrap an object to intercept operations.

const handler = {
    get: function(obj, prop) {
        return prop in obj ? obj[prop] : "Not found";
    }
};

const p = new Proxy({}, handler);
p.a = 1;
console.log(p.a); // 1
console.log(p.b); // "Not found"
Tamil Explanation
Proxy: ஒரு செக்யூரிட்டி கார்டு (Security Guard) போல. வீட்டுக்குள் (Object) யாராவது போகும்போதோ அல்லது எதையாவது எடுக்கும்போதோ, அவர் சோதனை செய்வார் (Intercept).
